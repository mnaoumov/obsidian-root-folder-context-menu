Welcome to the [Root Folder Context Menu](https://github.com/mnaoumov/obsidian-root-folder-context-menu/) demo vault. In a stock Obsidian vault, right-clicking the **vault root** in the File Explorer (the top row with your vault's name) - or the **empty area** below the file list - does nothing: neither has a context menu. This plugin gives both the same right-click menu that every other folder already has, so you can create a note, folder, or canvas at the top level straight from there.

**How to try it:** open the **File Explorer** (`Ctrl/Cmd+Shift+E`), **right-click the vault-name row at the very top**, and pick **New note** or **New folder** - it is created at the vault root. Then try right-clicking the blank space below the last file for the same menu.

> [!TIP] Interactive buttons
>
> The two setup notes have **Run** buttons, powered by [`CodeScript Toolkit`](https://github.com/mnaoumov/obsidian-codescript-toolkit/), which this vault installs for you automatically on first open (see [[04 CodeScript Toolkit prerequisite]]). The feature itself is a manual right-click action, so the feature notes have no buttons - just walk through them.
