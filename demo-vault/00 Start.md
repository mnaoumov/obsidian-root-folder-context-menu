# Start here

Welcome to the [Root Folder Context Menu](https://github.com/mnaoumov/obsidian-root-folder-context-menu/) demo vault. In a stock Obsidian vault, right-clicking the **vault root** in the File Explorer (the row at the very bottom of the left sidebar showing your vault's name; on mobile, the vault name at the top of the left drawer) - or the **empty area** below the file list - offers only a short menu of its own, nowhere near what every other folder gets. This plugin gives both spots that full folder menu, so you can create a note, folder, or canvas at the top level straight from there.

**How to try it:** open the **File Explorer** (`Ctrl/Cmd+Shift+E`), **right-click the vault-name row at the very bottom of the sidebar**, and pick **New note** or **New folder** - it is created at the vault root. Then try right-clicking the blank space below the last file for the same menu.

[01 Root folder context menu](<./01 Root folder context menu.md>) has buttons that turn the plugin off and on again, so you can see both menus back to back rather than take the claim on trust.
