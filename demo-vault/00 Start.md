# Start here

Welcome to the [Root Folder Context Menu](https://github.com/mnaoumov/obsidian-root-folder-context-menu/) demo vault. In a stock Obsidian vault, right-clicking the **vault root** in the File Explorer (the row at the very bottom of the left sidebar showing your vault's name) - or the **empty area** below the file list - does nothing: neither has a context menu. This plugin gives both the same right-click menu that every other folder already has, so you can create a note, folder, or canvas at the top level straight from there.

**How to try it:** open the **File Explorer** (`Ctrl/Cmd+Shift+E`), **right-click the vault-name row at the very bottom of the sidebar**, and pick **New note** or **New folder** - it is created at the vault root. Then try right-clicking the blank space below the last file for the same menu.
