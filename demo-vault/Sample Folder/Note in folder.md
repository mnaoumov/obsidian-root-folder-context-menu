# Note in folder

This note lives inside **Sample Folder** so the File Explorer has some structure to explore.

Right-click **Sample Folder** itself (or any ordinary folder) and you will see Obsidian's normal folder context menu - that has always worked. The point of this plugin is that the **vault root** and the **empty area** get the same menu, which they normally do not. See [[01 Root folder context menu]] and [[02 Empty area context menu]].
